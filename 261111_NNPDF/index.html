Shapley method:

Interpreting shapley values for PDF

  • Players: the 8 flavors \(\Sigma, g, V, V_3, V_8, T_3, T_8, T_{15}\)

  • Move: Gaussian bump at \(x_\mu\), amplitude = 68% replica band

  • Payoff: \(v(S)=\chi^2\) with the flavors in \(S\) bumped

8 flavors ⇒ \(2^8=128\) coalitions: exact computation

Bump applied in both directions and averaged; sum rules restored on the non-perturbed flavors. Exact: no SHAP-like independence approximation.

We have a quantitative sensititivity tool

  • A map of which flavor the data constrain, and where
  • Hyperopt: 4 folds, each meant to represent the whole dataset, built by hand
  • Can we build the folds with sensitivity quantified?

From datasets to fold profiles

1. One map per dataset \[ \mathbf v_d = \{\phi_{d,f}(x_i)\}_{f,i} \]
the dataset's own heatmap:
every flavor \(f\) at every \(x_i\)
→
2. Fold = sum of its datasets \[ \Phi_{k,f}(x_i) = \sum_{d\in F_k}\phi_{d,f}(x_i) \]
→
3. Target: a quarter of the data \[ t_f(x_i) = \tfrac{1}{4}\sum_{d}\phi_{d,f}(x_i) \]

20 most sensitive datasets: darker = more sensitive, color = optimized fold.

Data = always-fitted set A + movable set M, partitioned into K=4 folds; datasets never split. Fold profile is a sum thanks to the linearity of Shapley values. Shading = sum_f |phi_{d,f}(x)|.

Optimization: the intuition

\[ J = \frac{1}{K} \textcolor[RGB]{255,179,71}{\sum_{k}}\, \textcolor[RGB]{127,200,255}{\sum_{f}}\, \textcolor[RGB]{139,224,139}{\sum_{i}}\, w_{\textcolor[RGB]{127,200,255}{f}\textcolor[RGB]{139,224,139}{i}} \left[ \frac{\Phi_{\textcolor[RGB]{255,179,71}{k},\textcolor[RGB]{127,200,255}{f}}(x_{\textcolor[RGB]{139,224,139}{i}})-t_{\textcolor[RGB]{127,200,255}{f}}(x_{\textcolor[RGB]{139,224,139}{i}})}{s_{\textcolor[RGB]{127,200,255}{f}}} \right]^2 \]

each fold should match the target for every flavor at every \(x\)

Constraints
  • Datasets are never split
  • Each fold has at least one dataset of every process type (DIS, DY, jets, \(t\bar t\), …)
  • Fold sizes: \(n_{\min} \le n_k \le n_{\max}\)
How
  • Greedy start: largest datasets first, each into the fold least aligned with it
  • Solver (MIQP) refines it and bounds the remaining gain
J = 0 iff all folds identical. w_fi: equal per flavor and per log x interval; s_f: per-flavor scale with a floor. Greedy keeps feasibility: a placement is accepted only if the remaining datasets can still meet the size bounds (integer solver check).

Summary

  • Shapley maps turn "each fold represents the data" into a quantitative objective
  • Optimised folds: Objectif function close to optimal, valence and \(T_3\) blind spots removed
  • The limit is granularity (indivisible datasets), not the optimizer
  • What matters is how \(J\) is defined, not how it is minimized

Objective in detail

\[ J = \frac{1}{K} \textcolor[RGB]{255,179,71}{\sum_{k=1}^{K}}\, \textcolor[RGB]{127,200,255}{\sum_{f=1}^{8}}\, \textcolor[RGB]{139,224,139}{\sum_{i=1}^{N_x}}\, w_{\textcolor[RGB]{127,200,255}{f}\textcolor[RGB]{139,224,139}{i}} \left[ \frac{\Phi_{\textcolor[RGB]{255,179,71}{k},\textcolor[RGB]{127,200,255}{f}}(x_{\textcolor[RGB]{139,224,139}{i}})-t_{\textcolor[RGB]{127,200,255}{f}}(x_{\textcolor[RGB]{139,224,139}{i}})}{s_{\textcolor[RGB]{127,200,255}{f}}} \right]^2 \]

sum over folds \(k\)  ·  flavors \(f\)  ·  \(x\) points \(i\)

  • Signed: penalizes differences in both shape and magnitude, keeps tension (\(\phi<0\)) information
  • \(w_{fi}\): equal per flavor and per interval of \(\log x\)  ·  \(s_f\): per-flavor scale, with a floor for insensitive flavors
  • \(J=0\) iff all four folds have identical profiles

Assignment \(z_{dk}\in\{0,1\}\), each dataset in exactly one fold, plus fold-size bounds:

\[ \sum_{k} z_{dk}=1, \qquad n_{\min} \leq \sum_{d\in M}n_d\, z_{dk} \leq n_{\max} \]

⇒ a mixed-integer quadratic program (MIQP): the solver also returns a lower bound on \(J\).

Greedy construction of the folds

Adding \(d\) to fold \(k\) changes the objective by
\[ \Delta J_{dk}=\tfrac{1}{K}\big[2\langle\mathbf p_k-\mathbf t,\mathbf v_d\rangle_W+\|\mathbf v_d\|_W^2\big] \]
The \(\mathbf t\) and \(\|\mathbf v_d\|^2\) terms are the same for every \(k\):
\[ k^\star=\arg\min_k \langle\mathbf p_k,\mathbf v_d\rangle_W \]
  • Least aligned fold wins; partial folds are never compared to \(\mathbf t\), so no bias from incompleteness
  • Largest first: big datasets are the hardest to place once folds are nearly full
  • Feasibility: the integer solver checks that the remaining datasets can still meet the size bounds; current sizes alone can lead to a dead end
  • Signed profiles: anti-aligned placements (cancellations) are allowed, and flagged by the \(\phi^+/\phi^-\) diagnostics

MIQP refinement and diagnostics

MIQP solver
  • Minimize \(J\) under assignment + size constraints, starting from the greedy partition
  • Stop at time limit or optimality tolerance
  • Keep best partition + solver lower bound: separates "found a good partition" from "little improvement remains"
  • If the full search is too expensive: re-optimize subsets of datasets, others fixed
Diagnostics
  • Benchmark: original folds
  • \(J\) is an average: monitor the largest local imbalance
  • Unnormalized profiles
  • \(\phi^+\) and \(\phi^-\) contributions separately (cancellations)

Optimality claims apply to the chosen objective and constraints only.

Shapley value weights

\[ w(S) = \frac{|S|! \, (|N| - |S| - 1)!}{|N|!} = \frac{1}{n}\cdot\frac{1}{\binom{n-1}{s}} \]
  • \(1/n\): probability that \(i\) arrives in position \(s+1\)
  • \(1/\binom{n-1}{s}\): probability that its \(s\) predecessors are exactly \(S\)
  • ⇒ \(w(S)\) is the probability, over uniformly random orders, that \(i\) walks in right after \(S\)
